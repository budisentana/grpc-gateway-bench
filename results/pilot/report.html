QSBG benchmark: sandbox pilot

Sandbox pilot, not paper data. One 2-vCPU cloud VM, everything on localhost, no network emulation, gateway pinned to one core with the backend and load generator sharing the other. These numbers show the code and analysis work end to end; the paper's figures must come from the lab runs.

Statistical tests

Mann–Whitney U between configurations, Holm-corrected within each condition. With 3 repetitions per group the exact test cannot go below p = 0.1, so nothing here can reach significance; this checks the analysis pipeline. The lab runs need at least 6 repetitions.

Reproduce

go build -o bin/ ./cmd/...
./bin/certgen -out certs
GW_CPUS=0 GW_PROCS=1 BE_CPUS=1 LG_CPUS=1 scripts/run_pilot.sh results/pilot
python3 analysis/make_report.py results/pilot/summary report.html
